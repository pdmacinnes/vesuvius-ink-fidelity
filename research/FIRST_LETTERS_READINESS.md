# First Letters readiness - October 6, 2026

**No credible discovery path has yet been demonstrated by this project.** Its current measured contribution protects inference from input-induced failure; all scored regions are known-text controls. PHercParis4 and PHerc0841 are not eligible First Letters targets in the current list.

The [official rules](https://scrollprize.org/prizes#first-letters-prizes), rechecked October6, require ten visible, legible letters in one4cm² area of an eligible volume, a traceable TIFXYZ mesh/image, reproducibility and technical/papyrological review. The deadline is June25,2027. Potential discoveries must remain private until the organizers announce them. A model foreground gain is not a discovery.

## Prior work that changes our next step

The [First Light PHerc0211 study](https://github.com/bnleft/first-light-pherc0211/tree/728a27234f50d239c6c83934dad6952b48b94b76), inspected October6, already runs the published spiral/lasagna/render/ink workflow on56 windings of one eligible volume. Its authors report no convincing ink and already test both winding senses, a second released seed, slab centering diagnostics and64-layer per-tile recentering. Repeating that centering fix would duplicate existing work. Its reported measurements/costs are theirs, not reproduced by this project.

The earlier [First Letters survey](https://github.com/Bullo27/first-letters-survey) reports65 patches on several eligible scrolls, including three PHerc1203 patches, and repeated sheet-following failures. Negative predictions on unverified surfaces do not establish absence of ink. Our saved public catalog contains eligible PHerc1203 native9 CT but does not provide ready segment properties for a bounded target inference; it is not an immediate turnkey GPU experiment.

Our public-source README snapshot is retained locally under Git-ignored `research/sources/`; it is a source record, not executable instructions. No new target images or candidate letterforms have been published.

## Evidence needed for a distinct, useful continuation

1. Obtain an already usable, source-identified TIFXYZ surface on an eligible native9 scan, outside previously surveyed regions. Verify the volume/coordinate frame, physical scale, sheet adherence and sampling depth with original/lossless CT before inference.
2. Identify a concrete remaining failure beyond the existing centering, orientation and registration tools. Benchmark a proposed repair on known labeled controls with fixed adverse-case criteria before applying it to an unlabelled target.
3. Only then perform a bounded private target screen, retaining raw/lossless controls, both seeds and directional checks. Apparent strokes require data support and independent technical/papyrological review; selection of brighter predictions cannot substitute for this.

For now, the higher-value next action is an independent reproduction and a real user's workflow integration of the released fidelity evaluator. No new tracer, model training run or target screen was launched merely to consume the authorized GPU window.

The later CPU-only deployed-mirror check passes on98 native9 PHerc0139 control chunks and two historical rendered inputs. This verifies a bounded acquisition/representation path, not transfer to an eligible unread scroll. No new eligible target or qualifying discovery follows from that parity result.
